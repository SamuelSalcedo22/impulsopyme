# Contribuir

1. Instala Node 22 LTS y ejecuta `npm install`.
2. Crea una rama: `git checkout -b feat/mi-cambio`.
3. Haz commits pequeños con prefijo (`feat`, `fix`, `test`, `docs`, `build`, `ci`).
4. Ejecuta `npm test` antes de subir.
5. Abre un pull request con la plantilla del repositorio.

Reglas de la interfaz: Atomic Design, tokens de `design/tokens.json`, textos solo en `public/i18n`, y mensajes de error de tres partes. Más detalle en [`docs/`](docs).
